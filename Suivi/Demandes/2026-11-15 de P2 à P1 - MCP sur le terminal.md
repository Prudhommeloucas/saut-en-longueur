# Brancher les MCP Roblox Studio et Blender sur ton terminal

## Demande

T-001 est cochée pour la partie outils (`rokit.toml`). Reste le branchement des MCP sur Claude Code en terminal, qui ne peut se faire que sur ta machine : suivre la partie « Claude Code en terminal en plus » de [[Installation]] (`claude mcp add ...` pour les deux serveurs), puis vérifier que `claude mcp list` les montre connectés. Profites-en pour lancer `rokit install` dans le projet.

## Pourquoi

Sans ces MCP, Claude ne peut piloter ni Studio ni Blender depuis ton terminal (constructions, imports, tests de jeu).
