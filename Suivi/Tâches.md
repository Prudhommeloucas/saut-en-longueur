# Tâches

Toutes les tâches du projet, communes aux trois postes. N'importe qui prend n'importe quelle tâche : la réserver d'abord dans `Suivi/En cours/` ([[Travailler à plusieurs]]). Le détail (dépendances, condition de fin) est dans [[Déroulé du développement]].

Le mot après le tiret indique le genre de travail, pour s'orienter, pas qui doit le faire.

Pour cocher : `- [x] T-101 Appel — Code (2026-11-15, P3)`. On ne modifie que la ligne de sa tâche, pour éviter les conflits.
