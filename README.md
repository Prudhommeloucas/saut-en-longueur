# Saut en longueur

Jeu Roblox développé à trois. Ce dépôt contient les notes du projet (un coffre Obsidian), le code et les sources des modèles, sons et images.

## Première fois sur le projet

Quatre gestes à faire soi-même, puis Claude s'occupe du reste.

1. **Accepter l'invitation** au dépôt GitHub `Prudhommeloucas/saut-en-longueur`.
2. **Installer** git, Claude Desktop, Obsidian, Roblox Studio et Blender, s'ils ne le sont pas déjà.
3. **Récupérer le dépôt.** Dans Claude Desktop, onglet Code, ouvrir n'importe quel dossier et demander :

   > Clone le dépôt https://github.com/Prudhommeloucas/saut-en-longueur dans mon dossier Documents.

4. **Ouvrir le dossier cloné** dans une nouvelle session Claude Code (onglet Code de Claude Desktop, ou `claude` dans un terminal placé dans le dossier) et écrire :

   > Configure mon poste.

Claude vérifie alors les logiciels, demande quel poste tu occupes, règle git, teste les connexions à Roblox Studio et à Blender, puis annonce ta première tâche. Il ne fait cette mise en place qu'une fois : ensuite, chaque session commence directement par la mise à jour du dépôt et la tâche en cours.

Si Claude ne propose pas la mise en place de lui-même à la première session, la phrase « Configure mon poste » la déclenche.

## Ensuite

- Ouvrir le dossier dans Obsidian (« Ouvrir un dossier comme coffre ») et commencer par la note `Projet`.
- Le plan complet est dans `Déroulé du développement`, l'avancement dans `Tableau de bord`.
- Les règles pour travailler à trois sont dans `Équipe/Travailler à plusieurs`.

## En cas de problème

Écrire à Claude ce qui ne marche pas : la procédure qu'il suit est dans `Équipe/Première session` et le détail de chaque logiciel dans `Équipe/Installation`.
